# TweetStreak Support

TweetStreak is an iPhone app for daily posting goals, activity heatmaps and streaks. This public repository contains support information. The app's source code is private.

## Get help

[Open a support request](https://github.com/weskcode/tweetstreak-support/issues/new) or browse [existing requests](https://github.com/weskcode/tweetstreak-support/issues).

Include the app version and build number shown in TestFlight, your iOS version, what you expected, what happened, and the steps that reproduce the problem. Screenshots are optional; remove identifying or private information first.

GitHub issues are public. Do not include passwords, OAuth tokens, API keys, email addresses, phone numbers, or private account/activity details. For a privacy question, start with a general question without personal information.

## Getting started

Complete the welcome pages, choose a daily posts goal, and select **Use manual tracking** to enter your own counts. Reply goals are optional in Settings. **Try sample data** opens an isolated read-only preview.

Automatic X tracking in version 1.0 is restricted to @weskcode. Other users can use manual tracking or sample data. Connecting X requires configured X developer access, and X API usage may incur charges. TweetStreak does not post to X or display post text or messages.

## Activity and widgets

Tap a day to inspect it. In manual mode, use **Edit today’s count** or **Edit today’s replies** to save counts. Goals and rest-day changes have effective dates. A question mark means activity is unavailable, rather than a known zero.

Widgets use the last saved summary. Open the app to refresh saved progress. iOS controls widget updates and background refresh, so updates are not guaranteed at a particular time.

## Reminders

Reminders are optional local notifications. Check reminder settings in the app and notification permission in iOS Settings. Quiet hours and rest days apply. Today’s nudges stop after the app has saved completion of all configured goals. Counts can be stale until the next save or sync; future reminders are conditional. Optional milestone notifications are separate from goal nudges.

## Protect your history

Install updates over the existing app. Do not delete the app to troubleshoot missing activity: local data can become unavailable after deletion or device loss. TweetStreak does not provide its own cloud backup or multi-device sync.

If history looks missing, avoid entering replacement counts or using **Delete local app data**. Report the version and steps without posting private data. Unreadable saved activity is not automatically replaced with a blank record.

**Disconnect X** removes this device's X credentials and stops reminders while retaining cached activity. **Delete local app data** is a separate, confirmed action that clears saved activity, goals, preferences and credentials on the device. Neither action deletes posts on X. Access granted to X can also be revoked in X's connected-app settings.
